# NOVA Studio — Creative Digital Agency

Креативное агентство с wow-эффектами. Кастомный курсор, scroll-анимации, marquee, magnetic buttons.

## Стек
- HTML + CSS + Vanilla JS
- Шрифты: Space Grotesk, DM Sans
- Тема: Dark, пурпурный/розовый акцент

## Навыки
- Custom cursor с mouse-following
- Hero text reveal анимации
- Marquee бегущая строка
- Magnetic buttons
- Masonry portfolio grid
- Gradient text и mix-blend-mode
- Двуязычность EN/RU
